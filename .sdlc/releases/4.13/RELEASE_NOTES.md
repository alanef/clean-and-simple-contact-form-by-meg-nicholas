# Release 4.13

**Date:** 2026-10-23
**Previous:** 4.12.3

## Highlights

The opt-in notice can now be dismissed and points to the opt-in screen. This comes from updating the bundled
opt-in library to 1.3.3. The readme gains a FAQ on reporting security bugs.

## What's New

### Features
- FAQ entry on where to report security bugs, through the Patchstack Vulnerability Disclosure Program.

### Fixes
- The opt-in notice could not be dismissed and came back on every page load.
- On sites running other Fullworks free plugins, the opt-in notice and menu could belong to the wrong plugin.
- Leaving the opt-in screen without choosing left the notice up for good. Visiting the contact form settings
  now shows the opt-in screen again until you click Allow or Skip.
- Deleting the plugin now also removes its opt-in setting (`CSCF_form_rendered`).

### Improvements
- The notice links straight to the opt-in screen.
- Bundled opt-in library updated from 1.2.4 to 1.3.3.

## Breaking Changes

None.

## Migration Guide

None. The stored opt-in choice (`CSCF_form_rendered`) and dismissals (`CSCF_notice_dismissed`) are kept.
